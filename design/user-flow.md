# 사용자 흐름

```text
[랜딩/설명]
    │
    ▼
[프로필·집 조건 입력]
    ├─ 입력 오류 → 필드 안내
    └─ 분석 실행
          │
          ▼
[주거비 결과]
    ├─ 월 환산 주거비
    ├─ 권장 상한
    ├─ 소득 대비 비율
    └─ AI 위험 등급/확률
          │
          ▼
[정책 후보]
    ├─ 사전진단 통과
    ├─ 상세조건 확인
    └─ 현재 입력상 우선순위 낮음
          │
          ▼
[정책 상세]
    ├─ 맞는 조건
    ├─ 맞지 않는 조건
    ├─ 수동 확인 조건
    └─ 공식 페이지 이동
          │
          ▼
[다음 행동 3개]
```

## 상태 정의

- 초기: 예시 입력과 흐름 안내
- 처리: Streamlit 폼 제출 후 로컬 계산
- 성공: 결과 카드, 차트, 정책 표, 실행계획
- 오류: 모델 파일 누락 등 원인과 `python scripts/bootstrap.py` 명령 표시
- 정책 없음: 공식 자가진단 재검색 안내
