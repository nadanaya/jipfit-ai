# 사용자 흐름

```text
[랜딩/설명]
    │
    ▼
[프로필·집 조건 입력]
    ├─ 입력 오류 → 필드 안내
    └─ 분석 실행
          │
          ▼
[주거비 결과]
    ├─ 순수 월 주거비
    ├─ 주거·부채 통합 고정비
    ├─ 생활 안정 권장선 대비 초과·여유
    └─ AI 참고 위험도
          │
          ▼
[정책 사전진단]
    ├─ 높은 적합도
    ├─ 확인 필요
    └─ 핵심요건 미충족
          │
          ▼
[정책 상세]
    ├─ 맞는 조건
    ├─ 맞지 않는 조건
    ├─ 수동 확인 조건
    └─ 공식 페이지 이동
          │
          ▼
[다음 행동 3개]
```

## 상태 정의

- 초기: 예시 입력과 흐름 안내
- 처리: Streamlit 폼 제출 후 로컬 계산
- 성공: 종합 판정, 비교 막대, 정책 카드, 실행계획
- 오류: 모델 파일 누락 등 원인과 `python scripts/bootstrap.py` 명령 표시
- 정책 없음: 공식 자가진단 재검색 안내
