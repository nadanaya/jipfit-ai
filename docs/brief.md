# 프로젝트 브리프

## 프로젝트

- 팀: **원루프랩 (OneRoof Lab)**
- 서비스: **집핏 AI (JipFit AI)**
- 개발 조건: 1인 팀, 4일
- 선택 주제: 청년 주거 금융 도우미

## 문제 정의

청년은 집을 알아볼 때 월세, 관리비, 보증금, 부채상환, 생활비를 따로 계산하고, 자신에게 맞을 수 있는 정책도 여러 사이트에서 다시 찾아야 한다. 이 과정에서 “이 집을 실제로 감당할 수 있는가”와 “어떤 지원부터 확인해야 하는가”를 빠르게 판단하기 어렵다.

## 대상 사용자

- 만 19~39세 무주택 청년
- 첫 독립이나 이사를 준비하는 1인 가구
- 보증금·월세 대출 또는 공공임대·월세지원을 처음 알아보는 사용자

## 핵심 사용자 시나리오

1. 사용자가 소득·자산·희망 지역과 검토 중인 집의 비용을 입력한다.
2. 시스템이 보증금을 월 비용으로 환산하고 총 주거비를 계산한다.
3. 권장 주거비 상한, AI 부담 위험, 남는 생활비를 보여준다.
4. 정책별 통과 조건, 불일치 조건, 추가 확인 조건을 분리해 설명한다.
5. 사용자가 공식 자가진단과 최신 모집공고로 이동한다.

## 프로토타입 범위

- 월 주거비 통합 계산: 월세 + 관리비 + 보증금 기회비용
- 소득·부채·생활비 버퍼 기반 권장 주거비
- 합성 데이터 기반 3단계 부담 위험 분류
- 청년월세 지원사업, 행복주택 청년계층의 단순화 사전진단
- 청년버팀목전세자금 등 정책 탐색 후보 제공
- Streamlit 웹 데모와 SQLite 익명 분석 로그

## 제외 범위

- 실제 대출 승인·금리 산정
- 정책 수급 자격 확정
- 개인 신용정보·계좌정보 수집
- 실시간 부동산 매물 추천
- 실제 금융상품 가입 연결

## 성공 지표

- 사용자가 90초 안에 분석을 완료
- 동일 입력에서 결과가 재현됨
- 모든 정책 추천에 통과·불일치·수동 확인 이유가 표시됨
- 모델이 다수 클래스 기준선보다 macro F1 0.15 이상 개선
- 핵심 Python 테스트와 SQLite 검증 통과
