# 개인정보·안전 설계

## 수집하지 않는 정보

- 이름, 주민등록번호, 전화번호, 이메일
- 계좌번호, 신용점수, 거래내역 원문
- 상세 주소, 회사명, 자유서술 민원

## 저장하는 정보

데모 로그를 켠 경우 나이, 월소득, 자산, 지역 코드, 계산 결과, 규칙 기반 부담 단계, AI 참고 위험도, 정책 ID만 익명 UUID와 함께 SQLite에 저장한다.

## 안전 원칙

- 결과를 대출 승인이나 정책 자격 확정으로 표현하지 않는다.
- 공식 페이지 확인일을 표시하고, 변동 가능성을 고지한다.
- SQL은 문자열 결합 대신 파라미터 바인딩을 사용한다.
- 합성 데이터만 저장소에 포함하며 실제 개인 데이터는 포함하지 않는다.
