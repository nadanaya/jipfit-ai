# 3분 데모 스크립트

## 데모 전 준비

```bash
cd jipfit-ai
streamlit run app.py
```

브라우저에서 기본 예시가 보이는지 확인한다. 인터넷이 끊겨도 핵심 분석은 로컬에서 동작한다.

## 0:00~0:25 문제

“청년이 집을 볼 때 월세만 보고 결정하면 관리비, 보증금의 기회비용, 부채 때문에 실제 생활비가 부족해질 수 있습니다. 지원정책도 여러 페이지에 흩어져 있어 어떤 것부터 볼지 어렵습니다.”

## 0:25~0:45 해결책

“원루프랩의 집핏 AI는 소득·자산·지역과 검토 중인 집의 비용을 입력하면 권장 주거비, AI 부담 위험, 정책 후보와 확인 이유를 한 번에 보여줍니다.”

## 0:45~1:30 입력과 분석

기본 예시를 그대로 사용한다.

- 27세, 월소득 300만원
- 서울, 보증금 1,000만원
- 월세 65만원, 관리비 10만원
- 월 부채상환 20만원

`내 주거 선택 분석하기`를 누른다.

“집핏은 월세와 관리비뿐 아니라 보증금을 연 4% 기회비용으로 월 환산합니다. 권장 상한은 소득의 30%와 최소 생활비·저축 버퍼를 남기는 값 중 더 보수적인 값을 택합니다.”

## 1:30~2:10 AI와 정책 설명

AI 위험등급과 확률 차트를 보여준다.

“분류 모델은 합성 시나리오 6천 건으로 학습한 프로토타입입니다. 대출 승인 모델이 아니라, 여러 비용이 동시에 겹칠 때 위험 패턴을 보여주는 데모입니다.”

정책 표와 상위 정책 상세를 연다.

“정책은 단순 추천 점수만 주지 않습니다. 맞는 조건, 맞지 않는 조건, 공식 페이지에서 추가 확인할 조건을 분리합니다. 그래서 사용자가 왜 이 정책을 보게 되었는지 설명할 수 있습니다.”

## 2:10~2:40 차별점

“핵심 차별점은 세 가지입니다. 첫째, 정책을 보기 전에 이 집이 감당 가능한지 계산합니다. 둘째, 규칙 계산과 ML을 분리해 설명 가능성을 확보했습니다. 셋째, 이름·계좌·상세주소 없이 작동합니다.”

## 2:40~3:00 확장

“다음 단계에서는 국토교통부 실거래 임대료, 지자체 정책 API, 동의 기반 익명 현금흐름을 연결해 실제 지역별 추천과 정책 자동 갱신으로 확장하겠습니다.”

## 실패 시 대체 흐름

- 앱이 열리지 않으면 `python scripts/run_demo.py` 결과를 터미널에서 시연
- 모델 파일 오류면 `python scripts/bootstrap.py` 실행
- 인터넷이 끊기면 공식 링크 이동을 생략하고 로컬 결과만 시연
- 발표 직전에는 `assets/demo_result.json`을 백업 화면으로 준비
