# 대회 주제 적합성

주제 요구사항을 프로토타입 기능으로 직접 연결한다.

| 주제 요구 | 집핏 AI 구현 |
|---|---|
| 소득·자산·거주 희망 지역 분석 | 사용자 입력과 지역 데모 지수로 프로필 구성 |
| 이용 가능한 청년 금융지원 제도와 주거 금융 정보 추천 | 공식 출처 기반 정책 카탈로그와 설명 가능한 사전진단 |
| 월세·관리비·생활비를 종합 고려 | 월세·관리비·보증금 환산·부채상환액을 함께 계산하고 기타 지출 차감 전 잔액을 표시 |
| 적정 주거비 제안 | 월소득 30% 기준 생활 안정 권장선과 주거·부채 통합 고정비를 비교 |
| 합리적 주거 의사결정 지원 | 종합 판정, AI 참고 위험도, 정책 사전진단, 다음 행동 3개를 한 화면에 제공 |

## 차별점

1. **정책 목록 나열이 아니라 선택 중인 집의 감당 가능성부터 계산**한다.
2. 추천 결과를 `핵심요건 미충족`, `확인 필요`, `맞는 조건`, `공식 확인 조건`으로 분해한다.
3. 규칙 기반 금액 계산과 ML 위험 추정을 분리해 설명 가능성과 AI 데모를 모두 확보한다.
4. 이름·전화번호·계좌번호 없이 작동하는 개인정보 최소화 구조다.
