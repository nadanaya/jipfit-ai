# 발표자료 7장 구성

## 1. 문제 — 월세만 보면 실제 부담을 놓친다

- 월세 + 관리비 + 보증금 + 부채 + 생활비를 따로 계산
- 정책은 여러 사이트에 흩어짐
- 질문: “이 집을 감당할 수 있고, 어떤 지원부터 확인해야 할까?”

## 2. 해결 — 집핏 AI

- 입력 1회
- 생활 안정 권장선 대비 초과·여유
- 규칙 기반 부담 단계와 AI 참고 위험도
- 정책 사전진단 결과와 이유
- 다음 행동 3개

## 3. 사용자 흐름

`조건 입력 → 부담 분석 → 정책 설명 → 공식 확인`

화면 캡처 2장을 배치한다.

## 4. 기술 구조

- 투명한 규칙 기반 주거비 계산
- 합성 데이터 기반 분류 모델
- 공식 출처 기반 정책 사전진단
- Streamlit + SQLite

## 5. 검증

- 기준 모델과 후보 모델 비교
- macro F1, 혼동행렬
- 단위·통합 테스트
- SQLite 무결성 검증
- 합성 데이터라는 한계를 명시

## 6. 차별점·안전성

- “추천”보다 “왜”를 설명
- 정책 자격 확정과 사전진단을 구분
- 개인정보 최소화
- 오프라인 핵심 데모 가능

## 7. 확장·기대효과

- 실거래 임대료·관리비 데이터
- 정책 기준 자동 갱신
- 동의 기반 금융 현금흐름
- 은행 상담 전 사전 준비 도구

마지막 문장:

> 집핏 AI는 청년에게 집을 추천하기 전에, 그 집이 청년의 삶을 지킬 수 있는 선택인지 먼저 계산합니다.
