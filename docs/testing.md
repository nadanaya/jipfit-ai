# 검증 전략

## 자동 검증

```bash
python scripts/validate_project.py
```

이 명령은 다음을 순서대로 확인한다.

1. 필수 파일 존재
2. Python 문법 컴파일
3. SQLite 스키마·시드·대표 쿼리·무결성 테스트
4. Pytest 단위·통합 테스트
5. CLI 전체 분석 흐름
6. 선택 모델이 다수 클래스 기준선보다 충분히 개선됐는지 확인

## 수동 검증

- 앱 입력 최소·최대값
- 정책 결과의 공식 링크
- 모바일 폭에서 카드가 읽히는지
- 위험·주의·안정 세 가지 입력 시나리오
- 인터넷 차단 상태에서 핵심 분석

## 미검증

- 실제 정책 신청 결과와 일치율
- 실제 청년의 장기 연체·주거 이동 결과
- 실제 은행 대출 승인 결과
- 대규모 동시 사용자 성능
