# 집핏 AI — 한 장 요약

## Team

**원루프랩 (OneRoof Lab)** / 1인 팀

## 문제

청년은 집을 구할 때 월세뿐 아니라 관리비, 보증금, 부채, 생활비를 함께 계산해야 하고, 여러 곳에 흩어진 주거정책도 따로 확인해야 한다.

## 해결

소득·자산·희망 지역과 집 비용을 입력하면 다음을 한 번에 제공한다.

- 순수 월 주거비와 주거·부채 통합 고정비
- 월소득 30% 기준 생활 안정 권장선과 초과·여유 금액
- 규칙 기반 부담 단계와 AI 참고 위험도
- 핵심요건 미충족·확인 필요를 구분한 정책 사전진단 결과
- 다음 행동 3개

## 기술

- Streamlit
- Python / pandas / scikit-learn
- 규칙 기반 affordability engine
- 합성 데이터 6,000건 기반 분류 모델
- 설명 가능한 policy engine
- SQLite 익명 로그

## 검증

- 선택 모델: 로지스틱 회귀
- 합성 테스트셋 정확도: 0.9375
- 합성 테스트셋 Macro F1: 0.9185
- 다수 클래스 기준선 Macro F1: 0.2655
- Python 단위·통합 테스트와 SQLite 무결성 검증 포함

## 차별점

1. 정책을 추천하기 전에 선택한 집이 감당 가능한지 계산
2. 통과·불일치·수동 확인 조건을 분리해 설명
3. 규칙 기반 부담 단계와 AI 참고 위험도를 분리해 과도한 자동 판단을 방지
4. 이름·계좌·상세주소를 받지 않는 개인정보 최소화

## 한계와 확장

현재 학습 데이터와 지역지수는 데모용이다. 실제 임대료·관리비, 정책 갱신, 동의 기반 익명 현금흐름으로 검증한 뒤 금융 상담 전 사전진단 도구로 확장한다.
